Security roadmap

Before public launch, this product still needs server-side authentication, per-business data isolation, secure account recovery, staff permissions, encrypted cloud storage, automated backups, audit logs and independent security testing. Never put private API keys in this public HTML file.

Danger zone

Clears records stored in this browser. Download a backup first.

Security & Privacy Center

Control how your business data is handled on this device.

Prototype limitation: these controls apply only to this browser and device. Cloud accounts, server-side deletion and cross-device sync are not implemented. They cannot erase downloaded backups, screenshots, browser backups or other copies.

Don't Save My Data

When enabled, new changes remain temporary in this open tab and are not written to Nuvora's local storage. Existing saved records remain until you delete them. Refreshing or closing the tab can discard temporary changes.

Delete selected data

Choose categories to delete from this browser. Make a backup first if you may need these records later.

Clear current session

Reload the workspace. Temporary changes made while Don't Save My Data is on will be lost; already saved records remain.

Delete all my local data

Permanently removes all Nuvora records and preferences stored by this app in this browser. It does not remove downloaded backup files or other copies.
